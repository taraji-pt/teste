# MG4 Urban Calculator

PWA minimalista para cálculo rápido de carga, tempo e autonomia do MG4 Urban (53,9 kWh).

## Dados iniciais
- Bateria: 53,9 kWh
- Consumo real de referência: 13,2 kWh/100 km
- Potência habitual: 2,4 kW
- Eficiência de carga: 90%
- Energia: €0,18/kWh

## GitHub Pages
1. Criar um repositório, por exemplo `mg4-urban-calculator`.
2. Copiar todos os ficheiros para a raiz.
3. Settings → Pages → Deploy from branch → `main` / `/root`.
4. Abrir a URL no Safari do iPhone.
5. Partilhar → Adicionar ao ecrã principal.

Os valores de configuração são guardados localmente no dispositivo.
